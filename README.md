# Geosjobby Website

An early personal website project built while I was learning front-end web development.

This repository contains the source for a small portfolio-style landing page created around 2022. It is a snapshot of my earlier experiments with HTML, CSS, layout, animation and web design.

## Built with

- **HTML** — page structure and content
- **CSS** — layout, styling, gradients and animations
- **Animate.css** — entry and hover-style animations
- **Font Awesome** — navigation icons
- **Google Fonts** — typography

## Project structure

```
.
├── Assets/
│   └── Favicon.jpg
├── Css/
│   ├── Global.css
│   └── Index.css
├── Js/
│   └── Main.js
├── index.html

```

## Running locally

No build tools or package installation are required.

1. Clone or download this repository.
2. Open `index.html` in a web browser.

The page loads its styles and assets using relative paths. Some fonts, icons and animations are loaded from external CDNs, so those features require an internet connection.
